# ADR-0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-11
- **Deciders:** Chad

## Context

This is a large project built by a very small team over a long time. Decisions about the engine, the sync model and licensing will be questioned later, by future contributors and by ourselves.

## Decision

Every decision with lasting consequences gets a short record in `docs/adr`, numbered in order, using `0000-template.md`.

## Alternatives considered

- **A wiki or external document.** It drifts from the code and is not reviewed with it.
- **Nothing.** The reasoning is lost and the same debates repeat.

## Consequences

A small writing cost per decision. Accepted records are not edited; a new record supersedes them, so the history stays readable.

## How we will know

A new contributor can answer "why is it like this?" from the repo alone.
